# Program Baseline Intake

Owner workflow: `adp-plan-baseline`

The starter JSON beside this file is deliberately incomplete. Replace every `TBD` only with source-backed, owner-confirmed facts. Do not infer approved plan dates from action due dates, meeting language, model estimates, or roadmap placeholders.

Confirm before creation:

- project owner and target date
- phase gates and planned dates
- workstream milestones and planned dates
- stable IDs, owners, dependencies, and critical-path membership
- source anchors and confirming authority
- schedule tolerance and optional auditable weighting

Run `adp-plan-baseline propose` first. A missing baseline is an onboarding gap, not evidence that the project is late.
