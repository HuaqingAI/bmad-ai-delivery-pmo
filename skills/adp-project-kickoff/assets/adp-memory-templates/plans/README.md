# Program Plans

`program-baseline.md` is the approved project plan fact source and is owned only by `adp-plan-baseline`. Kickoff intentionally does not create an empty baseline because that would be indistinguishable from an approved revision.

Use `intake/program-baseline-candidate.json` to collect source-backed project targets, gates, milestones, dependencies, and critical-path candidates. After confirmation, run `adp-plan-baseline propose` and then its preview-before-execute create flow.

Prior approved revisions are archived under `baseline-history/`. Do not edit the current baseline or archived revisions manually.
